# Live-trades foreground revision

The native ImageGen background is preserved. The editable SVG foreground now displays four distinct KOLs from the app's roster: Afeng (@aa_AFeng), Tavern (@TurtleTavernTV), 0xAA (@0xAA_Science), and Cupsey (@Cupseyy).

The public API supplies each original avatar, token image, trade side, amount, contract, transaction hash, and timestamp. Two actual buys and two actual sells are sorted newest first. Dates identify the 11–12 October 2026 activity explicitly. Names and avatars are emphasized; actual token names and artwork appear below them.

Foreground typography uses Manrope, with the app's Microsoft YaHei fallback for Chinese token names. No trade or endorsement was generated. See `../shared/live-kols-snapshot.json` and `../refresh-live-kols.mjs` for the saved data and read-only refresh process.
